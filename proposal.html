1. Source Selection Plan (Sample Application)

Candidate Laravel applications we plan to evaluate. The final choice will be confirmed for Milestone 2. Features listed are taken from each repository's README and will be verified in the source code.

No. Application GitHub URL Licence Features covered (per README)
1 Blog REST API Laravel github.com/thatal/blog-rest-api-laravel MIT REST API for a blog, user authentication with Sanctum, CRUD for posts, categories and comments, basic tests
2 Laravel 12 CRUD Application github.com/ManushaUm/laravel12-CRUD-application MIT RESTful CRUD endpoints, MySQL database, Laravel authentication, React starter-kit frontend
3 Laravel RealWorld Example App github.com/adr1enbe4udou1n/laravel-realworld-example-app MIT RealWorld-spec REST API, CRUD, authentication, routing, pagination, tested with Pest

Selection criteria

  • Database connection, REST API with data validation, form validation, session management, file uploading and error handling
  • Contains code for a variable with scope, a non-trivial expression, selection, loop, error-handling block, and a function with parameters and a return value
  • Can be deployed on a free server
  • Licence allows reuse, and the code is small enough for every member to explain
